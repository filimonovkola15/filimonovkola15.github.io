# TVOЁ Online Cinema Clone

Это точная копия дизайна и стиля онлайн-кинотеатра TVOЁ, созданная на основе скриншотов.

## Технологии
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## Страницы
- **Главная (`index.html`)**: Основной лендинг с героем, шортсами, новинками и ТОП-10.
- **Фильмы (`movies.html`)**: Сетка фильмов с фильтрами.
- **Сериалы (`series.html`)**: Сетка сериалов.
- **Плеер (`player.html`)**: Страница просмотра с видео-заглушкой.

## Как запустить
Просто откройте файл `index.html` в любом современном браузере.

## Особенности
- Темная тема с акцентным лаймовым цветом.
- Плавные анимации появления и ховер-эффекты.
- Адаптивный дизайн (базовый).
- Горизонтальная прокрутка рядов (поддерживает перетаскивание мышью).
- Высококачественные изображения и видео-трейлеры из открытых источников.
